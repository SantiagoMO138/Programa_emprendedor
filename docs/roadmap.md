# Roadmap

## POC

**Resultado:** demostración navegable del configurador y del flujo completo sin cobro ni publicación reales.

Hitos: página comercial, tres presets, personalización controlada, vista previa responsiva, checkout simulado, formulario de ventas y entorno Docker Compose para desarrollo y pruebas locales.

## Fase 1: producto comercial

**Resultado:** cliente registrado con un sitio estándar publicado automáticamente después de validar su pago.

Hitos: modelo de datos, cuentas, guardado de configuración, pedidos, comprobantes, validación administrativa, aprovisionamiento, subdominios, notificaciones y panel de cliente.

## Fase 2: escalamiento

**Resultado:** catálogo más amplio, ciclo de suscripción maduro y operación fiable a escala.

Hitos: nuevos presets, versiones, analítica, automatización financiera, copias de seguridad, alertas y CRM de ventas personalizadas.

## Dependencias

Antes de la publicación real se necesitan el dominio principal, una cuenta de Cloudflare, un proyecto Supabase, una política operativa para validar pagos y un proveedor de notificaciones. El e-commerce requiere además definir el proveedor de cobro de las tiendas.
