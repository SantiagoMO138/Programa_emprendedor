# Configurador de sitios

El configurador permite editar solo colores, tipografías, logo, textos, imágenes y secciones predefinidas. No introduzcas edición libre de estructura ni controles que produzcan configuraciones no publicables.

Usa una `SiteConfiguration` tipada y validada tanto en cliente como en servidor. Conserva los modos de vista previa de escritorio y móvil, y presenta una ruta visible a ventas cuando el usuario necesita una capacidad fuera del preset. Consulta [producto](../../../docs/producto.md) y [arquitectura](../../../docs/arquitectura.md).
