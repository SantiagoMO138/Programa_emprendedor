# Documentación del producto

Actualiza la documentación afectada cuando cambie una decisión, requisito o flujo. Conserva los documentos en español, separa el autoservicio de los proyectos personalizados y no presentes como automático ningún paso que aún dependa de una persona.

Antes de documentar pagos o publicación, revisa las ADR en [docs/decisiones](../../../docs/decisiones). Las decisiones técnicas duraderas se registran como una nueva ADR en lugar de modificar el historial de una ADR aceptada.
